A dependency-free interpreter for [make.fun](https://make.fun)'s tiny stack ISA. It runs every program set under `MAKEFUN_INPUT_DIR` and writes each program's stdout and exit code under `MAKEFUN_OUTPUT_DIR`. Node 22, no dependencies, deterministic.
